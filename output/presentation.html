研究背景3

研究背景与动机

领域特征

优化理论 (Optimization Theory) 是应用数学的核心分支。从 1960 年代 Polyak 的重球法 (Heavy Ball Method)，到 1980 年代 Nesterov 的加速梯度 (Accelerated Gradient)，再到 2000 年代 Alvarez 和 Attouch 等人的惯性近端方法 (Inertial Proximal Methods)，50 年间形成了复杂的定理依赖网络。

一篇论文的定理往往需要引用多篇前人的结果作为前置条件。研究者理解一个新方法时，需要反复追溯其理论基础。

现存问题

  1. 信息碎片化：定理分散在 26+ 篇论文中，缺乏统一的结构化索引
  2. 关系不可见：传统文献综述以线性文本呈现，无法展示定理网络拓扑
  3. 重复发现：同一数学结果在不同论文中以不同形式出现，难以识别等价性
  4. 追溯困难：从应用结果反向追踪到基础定理需要多次人工跳转
核心问题：如何从非结构化的论文文本中自动提取数学断言，构建可查询、可探索的知识关系网络？

算法 · 阶段一9

阶段一：引用感知定理扫描

正则匹配模式

THM_DECLARE = re.compile( r'(?:^|\n)[ \t]*(THEOREM|Theorem|LEMMA|Lemma|' r'COROLLARY|Corollary|DEFINITION|Definition|' r'PROPOSITION|Proposition)[ \t]+(\d+\.?\d*)\.?', re.MULTILINE)

要求：定理标记必须出现在行首（前面只有可选的空白），必须有数字编号，可选句点结尾。同时匹配无编号的独立 "Theorem.\n" 行。

引用过滤规则

前文检查 (±35 字符): "by|using|from|see|in|of|applying|to|and" → 判定为引用, 丢弃候选 后文检查 (+15 字符): ", p." 或 "(see" 或 "[" → 判定为引用, 丢弃候选 行内检查: 不在行首 且 前一行为长文本 (>40字符) → 可能为行内引用, 丢弃候选
例："by Theorem 3.1, the sequence converges" → 引用，丢弃。而独立行首的 "Theorem 3.1. Let f be a convex function..." → 声明，保留。此步骤消除了大量因论文内交叉引用产生的假阳性定理提取。
算法 · 阶段二10

阶段二：多点边界定理体分割

边界集合构建

结构边界: · SECTION: r'(?:^|\n)#{1,3}\s+' (节标题) · REFERENCES: r'#{1,3}\s+REFERENCE' 内容边界: · PROOF_START: r'(?:^|\n)\s*(?:Proof|PROOF)\.?\s' 定理间边界 (关键设计): · 所有定理声明的起始位置 → 前一个定理的结束 = 下一个定理的开始

二次裁剪流程

一次提取: body = content[decl.end() : next_boundary] 二次裁剪: ├─ proof_m = PROOF_START.search(body) │ if proof_m: │ body = body[:proof_m.start()] └─ for d2 in later_declarations: if d2.start in body: body = body[:d2.start - body_start]
核心创新：将定理声明自身加入边界集合。当一个定理的边界结束于下一个定理的开始时，前一个定理的陈述文字不会"渗漏"到后一个定理中。二次裁剪进一步移除残留的证明文字和嵌套定理声明。无 LaTeX 率从 ~25% 降至 2.5%。

算法 · 阶段四12

阶段四：结构签名去重

LaTeX 结构签名算法

def latex_signature(latex): norm = re.sub(r'\s+', ' ', latex).strip() # 单字母变量 → X norm = re.sub(r'\b([a-zA-Z])\b(?=\s*[=+...])','X',norm) # 带下标变量 → XS norm = re.sub(r'\b([a-zA-Z])_\{[^}]+\}','XS',norm) # 数字 → N norm = re.sub(r'\b\d+\.?\d*\b','N',norm) # 保留所有 LaTeX 命令结构 (不折叠) return re.sub(r'\s+','',norm)[:200]

合并规则

分桶: 按签名前 40 字符哈希分桶 桶内比较: ├─ 精确签名匹配 → 直接合并 ├─ SequenceMatcher > 92% → 合并 └─ 同论文 + 不同名称 → 永不合并 合并策略: 保留最长的 statement 保留最长的 latex 合并所有 sources 列表

关键设计：旧版将所有 LaTeX 命令折叠为 "G"，导致不同定理产生相同签名。新版保留命令结构 (如 \nabla, \partial, \sup 等)，仅替换变量名和数字。签名截断到 200 字符以平衡精度和效率。

去重结果: 315 项中仅 3 组合并 (0.9%)。采用高度保守策略，避免将不同定理误判为等价。合并组包括: (1) Lemma 6+7 (1964) — LaTeX 结构高度相似; (2) Theorem 7+8 (1964) — 同上; (3) 跨论文的公式等价项。

阶段五：多策略关系发现

前置条件

两个候选条目必须共享 ≥ 2 个非类型关键词（即除去 "theorem", "lemma" 等类型标签之后的纯主题关键词），才会进入关系判定。这大幅减少了 O(N²) 的配对比较开销。

Derives (推导) — 1,529 条

Theorem → Corollary (置信度 0.80) Lemma → Corollary (score ≥ 3) Proposition → Corollary (score ≥ 3) // 推论天然来源于定理/引理/命题

Depends (依赖) — 2,309 条

Lemma → Theorem / Proposition (score ≥ 3) Definition → Any (score ≥ 2) Proposition → Theorem (score ≥ 3) 同论文相邻引理链 交叉引用: A 的名称出现在 B 的陈述中

同类型 + 同编号 + 跨论文 (score ≥ 3) LaTeX 签名相似度 > 92% 同类型 + 共享 ≥ 5 关键词 // 例: "Theorem 2.1" 在两篇论文中

算法 · 阶段六15

阶段六：中心辐射加权力导向布局

六步布局算法

Step 1 计算节点中心度 (degree centrality) Step 2 从 top-5 核心节点执行 BFS → 分配每个节点的深度环 (ring depth) Step 3 同心环初始放置 中心 (d=0) → 半径 30px 外围 (d=max) → 半径 MAX_RADIUS Step 4 加权弹簧精调 (120 轮): · 推导/推广 (w=1.0) → 目标距离 40px · 依赖 (w=0.5) → 目标距离 100px · 同论文 (w=0.15) → 目标距离 180px Step 5 网格加速排斥力 (grid_size=100) Step 6 硬性去重叠修正 (50 轮迭代)

设计原则

中心辐射核心节点居中，按图距离向外扩散
关系距离紧密关联的节点 → 空间距离近
同论文聚拢弱权重边使同论文节点轻微聚合
无碰撞NODE_SIZE + MIN_GAP 保证最小间距
静态渲染预计算所有坐标，浏览器端零力模拟
类型引力5 种节点类型各有引力中心 (质心)
权重映射公式： target_distance = 40 + (1.0 − weight) × 200。权重 1.0 的边 (推导) 目标距离 40px；权重 0.15 的边 (同论文) 目标距离 180px。这实现了"关系越紧密，空间距离越近"的直观映射。

⸻ 通俗理解 ⸻

可以将知识图谱比作学术家族树：红色实线是"父子"推导关系 (定理 → 推论)；橙色点线是"我需要你"的依赖关系 (引理支撑定理)；蓝色虚线是"我在你基础上拓展"的推广关系 (早期结果 → 后来推广)；绿色虚线是"我们本质相同"的等价关系 (不同论文的同一结果)；紫色极细线标记了出自同一篇论文的"手足"关系。五种颜色在白色背景上对比度均 ≥ 4.5:1 (WCAG AA 标准)。
