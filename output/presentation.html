项目动机

问题

优化理论领域 50 年间积累了海量定理、引理和算法。研究者需要反复查阅多篇论文来理解某一结果的前置依赖、推广关系和等价形式。

传统文献综述只能线性呈现，无法展示定理之间的复杂网络结构。

解决方案

构建自动化知识图谱系统，从论文 Markdown 中提取所有数学断言，建立推导 / 依赖 / 推广 / 等价四维关系网络。

生成交互式 2D 可视化，研究者可直观探索跨论文的知识关联。

阶段一 · 引用感知定理扫描

正则匹配

r'(?:^|\n)[ \t]*(THEOREM|Theorem|LEMMA|Lemma| COROLLARY|Corollary|DEFINITION|Definition| PROPOSITION|Proposition)[ \t]+(\d+)\.?'

必须出现在行首, 必须有编号, 可选句点

引用过滤规则

前文检查 (±35 字符): ├─ "by|using|from|see|in|of|applying|to|and" → 引用, 丢弃 后文检查 (+15 字符): ├─ ", p." "(see" "[" → 引用, 丢弃 行内检查: └─ 不在行首且前一行为长文本 → 很可能引用, 丢弃

核心改进: 区分 "Theorem 3, p.32" (论文内引用) 与真正的 "Theorem 3." (声明)

阶段二 · 多点边界定理体分割

边界集合构建

boundaries = set() # 结构边界 for m in SECTION.finditer(content): boundaries.add(m.start()) for m in REFERENCES.finditer(content): boundaries.add(m.start()) # 内容边界 for m in PROOF_START.finditer(content): boundaries.add(m.start()) # 相邻定理边界 (关键!) for decl in declarations: boundaries.add(decl['start'])

二次裁剪

一次提取: body = content[decl.end() : next_boundary] 二次裁剪: ├─ proof_m = PROOF_START.search(body) │ → body = body[:proof_m.start()] └─ for d2 in declarations: if d2 in body → body = body[:d2.start - body_start]

定理声明自身作为前一个定理的结束边界 → 消除语句渗漏

阶段三 · 公式提取与 ID 分配

公式提取策略

优先级 1: Display Math display = DISPLAY_MATH.findall(statement) core = 第一个长度 > 15 的公式 优先级 2: Inline Math (回退) inline = INLINE_MATH.findall(statement) significant = [f for f in inline if len(f) > 10] core = ' ; '.join(significant[:3]) Tag 公式合并: 按 position 将 \tag{...} 公式 合并到最近的前一个定理

阶段四 · 结构签名去重

LaTeX 签名算法

def latex_signature(latex): norm = re.sub(r'\s+',' ',latex).strip() # 单字母变量 → X norm = re.sub(r'\b([a-zA-Z])\b(?=\s*[=+...])','X',norm) # 带下标变量 → XS norm = re.sub(r'\b([a-zA-Z])_\{[^}]+\}','XS',norm) # 数字 → N norm = re.sub(r'\b\d+\.?\d*\b','N',norm) # 保留所有 LaTeX 命令结构 return re.sub(r'\s+','',norm)[:200]

合并规则

分桶: 按签名前 40 字符分桶 桶内比较: ├─ 精确签名匹配 → 合并 ├─ SequenceMatcher > 0.92 → 合并 └─ 同论文 + 不同名 → 永不合并 合并策略: 保留最长 statement + 最长 latex 合并所有 sources

结果: 315 项中仅 3 组合并 (高度保守, 避免误合)

阶段六 · 中心辐射布局

布局算法

1. 计算节点中心度 (degree) 2. 从 top-5 核心节点 BFS → 深度环 3. 同心环放置 (中心 = 高度数) 4. 加权弹簧精调 (120 轮): ├─ 推导/推广 (w=1.0) → 40px ├─ 依赖 (w=0.5) → 100px └─ 同论文 (w=0.15) → 180px 5. 网格加速防重叠 (O(n) bucket) 6. 硬性去重叠修正 (50 轮)

设计原则

中心辐射核心节点居中, 按图距离外扩
关系距离紧密关联 → 距离近
同论文聚拢弱权重边使同论文节点轻微聚合
无碰撞硬性最小间距 + 网格加速
静态渲染预计算坐标, 浏览器零力模拟
类型分散5 种类型各有引力中心
