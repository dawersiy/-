# 微积分基本定理

## 第 1 章 预备知识

### 定义 1.1（连续函数）
设函数 f 在区间 I 上有定义。如果对于任意 x₀ ∈ I 和任意 ε > 0，存在 δ > 0，
使得当 |x - x₀| < δ 且 x ∈ I 时，恒有 |f(x) - f(x₀)| < ε，则称 f 在 I 上连续。

### 定义 1.2（可导函数）
设函数 f 在点 x₀ 的某邻域内有定义。若极限
\[
\lim_{h \to 0} \frac{f(x₀ + h) - f(x₀)}{h}
\]
存在，则称 f 在 x₀ 处可导，极限值称为 f 在 x₀ 处的导数，记作 f'(x₀)。

### 定义 1.3（原函数）
设函数 f 与 F 在区间 I 上有定义。若对任意 x ∈ I 均有 F'(x) = f(x)，
则称 F 为 f 在 I 上的一个原函数。

### 引理 1.4（可导必连续）
若函数 f 在 x₀ 处可导，则 f 在 x₀ 处连续。

**证明**：
由可导性，存在极限
\[
\lim_{h \to 0} \frac{f(x₀ + h) - f(x₀)}{h} = f'(x₀).
\]
于是当 h → 0 时，
\[
f(x₀ + h) - f(x₀) = \frac{f(x₀ + h) - f(x₀)}{h} \cdot h \to f'(x₀) \cdot 0 = 0,
\]
故 f 在 x₀ 处连续。∎

## 第 2 章 积分理论

### 定义 2.1（定积分）
设 f 在 [a, b] 上有界。对 [a, b] 的任意分割
a = x₀ < x₁ < ... < xₙ = b 和任意选取的 ξᵢ ∈ [xᵢ₋₁, xᵢ]，
若 Riemann 和
\[
\sum_{i=1}^{n} f(ξᵢ)(xᵢ - xᵢ₋₁)
\]
当最大区间长度趋于 0 时的极限存在且唯一，则称 f 在 [a, b] 上 Riemann 可积，
极限值称为 f 在 [a, b] 上的定积分，记作 ∫ₐᵇ f(x)dx。

### 定义 2.2（变上限积分函数）
设 f 在 [a, b] 上可积。对任意 x ∈ [a, b]，定义
\[
Φ(x) = \int_{a}^{x} f(t) \, dt.
\]
称 Φ 为 f 的变上限积分函数。

## 第 3 章 核心定理

### 定理 3.1（微积分第一基本定理）
设 f 在 [a, b] 上连续，则变上限积分函数
\[
Φ(x) = \int_{a}^{x} f(t) \, dt
\]
在 [a, b] 上可导，且对任意 x ∈ (a, b)，有 Φ'(x) = f(x)。
换言之，连续函数的变上限积分是其原函数。

**证明**：
对任意 x ∈ (a, b) 和充分小的 h ≠ 0，
\[
\frac{Φ(x + h) - Φ(x)}{h} = \frac{1}{h} \int_{x}^{x+h} f(t) \, dt.
\]
由积分中值定理，存在 ξ 介于 x 与 x + h 之间，使上式等于 f(ξ)。
令 h → 0，由 f 的连续性，ξ → x，故 f(ξ) → f(x)。因此 Φ'(x) = f(x)。∎

### 定理 3.2（微积分第二基本定理 / Newton-Leibniz 公式）
设 f 在 [a, b] 上连续，F 是 f 的任一原函数，则
\[
\int_{a}^{b} f(x) \, dx = F(b) - F(a).
\]

**证明**：
由定理 3.1，Φ(x) = ∫ₐˣ f(t)dt 是 f 的一个原函数。
已知 F 也是 f 的原函数，故 F(x) = Φ(x) + C（原函数之间仅相差常数）。
代入 x = a，得 F(a) = Φ(a) + C = 0 + C，所以 C = F(a)。
代入 x = b，得 F(b) = Φ(b) + F(a)，即 Φ(b) = F(b) - F(a)。
而 Φ(b) = ∫ₐᵇ f(t)dt = ∫ₐᵇ f(x)dx，故结论成立。∎

### 推论 3.3（定积分的 Newton-Leibniz 计算方法）
若被积函数 f 在积分区间上连续且能找到其初等原函数，
则定积分的计算可转化为求原函数在区间端点的差值。

**证明**：这是定理 3.2 的直接应用。∎

### 推论 3.4（微积分基本定理的推广 — 对非连续被积函数的处理）
若 f 在 [a, b] 上仅有有限个间断点，但仍 Riemann 可积，
则定理 3.1 的结论在 f 的连续点处仍然成立。

**证明**：
将积分区间在每个间断点处分割，在每个子区间上应用定理 3.1，
再利用积分的区间可加性即可。∎
